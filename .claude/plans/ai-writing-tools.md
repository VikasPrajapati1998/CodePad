# Plan: better suggestions, spelling, grammar check, AI rewrite (v1.4)

Decisions (user): (1) suggestions stay on the built-in local Qwen3 with smarter context and complete-sentence/statement endings; cloud models are NOT used for suggestions. (2) Spelling = offline dictionary squiggles + quick fixes; grammar = on-demand AI command. (3) Rewrite/Restructure = on-demand AI command using the selected summary model, shown as a diff, applied only after confirmation, with a content-preservation check. Closing an unsaved file-less tab asks Yes/No (done in app.ts closeTabFromUi).

## 1. Suggestions (agent S1)
Problem seen: output is cut mid-sentence (24 tokens, stop at newline) and ignores the rest of the file (only `ai.contextChars` before the cursor).
- Context sent: (a) file header (first lines: #include/import/use block, front-matter) capped; (b) the enclosing function/method/class block (brace/indent based, regex/heuristic per language id; prose: the current paragraph plus the previous paragraph and the nearest heading), capped to the context budget; (c) text after the cursor (up to the end of the enclosing block, capped) so the model does not repeat what follows; fallback = last `ai.contextChars` chars.
- Completion length: allow more tokens (default 24 -> up to 64-96 by language kind) but stop at the first natural end: sentence end (. ! ? followed by space/newline) for prose; end of the statement (`;`, balanced `{}` block closed) or end of line for code; never end on a dangling word, unclosed bracket or quote (trim back to the last complete sentence/statement; drop the suggestion if nothing complete remains). Keep EOL-only ghost text and the cpAiGhostAtEol Right Arrow behaviour.
- Anti-repetition: do not suggest text that already appears right after the cursor or duplicates the last lines before it.
- Files: aiPrompts.ts (buildSuggestPrompt, cleanSuggestion), renderer/features/ai-suggest.ts (context extraction), aiIpc.ts (validateSuggestRequest limits only), aiEngine.ts/aiWorker.ts (suggest context size/limits only), shared/settingsSchema.ts (ai.* keys only). Context size of the suggest slot may grow (1024 -> 2048) if memory allows (document the cost). New request fields must be added to src/types/codepad-api.d.ts (`ai:suggest` args) and preload stays unchanged.

## 2. Spelling (agent S2)
- Offline Hunspell dictionary via `nspell` + `dictionary-en` (pin exact versions; justify in the report: no network, Electron's built-in spellchecker downloads dictionaries). Runs in main (`spellcheck.ts`), loaded lazily; personal words in userData/spell-words.json via userStore (size capped).
- IPC (handle()): `spell:check` (words: string[] up to 2000, each <= 64 chars) -> `{misspelled: {word, suggestions: string[]}[]}` ; `spell:addWord` (word) -> `{ok}`. Preload + `src/types/codepad-api.d.ts` additions.
- Renderer feature `renderer/features/spellcheck.ts`: Monaco markers (severity Info/Hint style squiggle) for languages plaintext and markdown, and for comments/strings of other languages only if cheap to tell; debounce 600 ms; skip words with digits, ALL-CAPS, URLs/emails, camelCase/snake_case tokens; quick fixes through registerCodeActionProvider (top 5 suggestions, "Add to dictionary", "Ignore"). Setting `spell.enabled` (bool, default true) in settingsSchema + settings panel entry + command `view.toggleSpellcheck`.
- Ship dictionary files via package.json build.files (node_modules entries) and document the licence in NOTICE.

## 3. Grammar check and Rewrite / Restructure (agents B3 backend, U3 UI)
Contract:
- Commands (shared/commands/ai.commands.ts): `ai.checkGrammar` ("Check Grammar and Spelling with AI...") and `ai.rewrite` ("Rewrite / Restructure with AI..."). Scope: selection if any, else whole file (text tabs only).
- IPC: `ai:rewrite:start({text, name, mode: 'grammar'|'restructure', instruction?: string (<=300 chars, restructure only), languageId})` -> `{ok, jobId}`; `ai:rewrite:cancel(jobId)`. Events on `ai:event`: `{type:'rewrite', jobId, phase: 'loading'|'progress'|'consentRequired'|'modelFailed'|'done'|'error'|'cancelled', current?, total?, text?, warnings?: string[], changes?: number, label?, modelId?, code?, message?}`. `done` carries the full new text. Consent (`ai:models:consent`) and the failure fallback (`ai:summarize:retryDefault(jobId)`) must work for rewrite jobs too (generalize the waiter, keep summary behaviour identical).
- Model routing = same as summaries (active model: builtin / local GGUF / remote). One text job at a time with summaries (shared busy flag).
- Pipeline (`rewriter.ts`, pure, injected complete(), unit-testable): split into chunks on paragraph/block boundaries sized to the model context (remote with big context: single pass); per chunk call with a strict system prompt (grammar: fix spelling/grammar/punctuation only, keep wording, meaning, line breaks, markup and code; restructure: improve structure/headings/ordering, keep every fact, number, name and code line; output only the text). Never drop chunks: on a failed chunk keep the original text for it and add a warning.
- Preservation check (docExtract helpers): numbers, URLs, e-mails, dates, identifiers and code-fence/line counts present in the input must be present in the output; for grammar mode also the length ratio must stay within 0.8-1.25 and line count within 10%; violations become `warnings`, and a chunk with severe loss falls back to its original text.
- Renderer flow (`renderer/features/ai-rewrite.ts`): progress status + Cancel, then open the result in the existing compare/diff view (original vs proposed) with a modal 'Apply' / 'Discard' (and the warnings listed); Apply replaces the text through `ctx.text` as ONE undoable edit (selection or whole file); nothing changes before Apply. Local Qwen3 shows a one-time notice that quality is limited for long text.
- Privacy: remote models need the same one-time consent; document text only in memory, never logged, rewrite results are not cached.

## 4. Order and ownership
S1 and S2 and U3 start in parallel; B3 starts after S1 finishes (both touch aiIpc.ts/aiWorker.ts/aiEngine.ts). Shared files (settingsSchema.ts, codepad-api.d.ts, preload.ts, ai.commands.ts, renderer-globals.d.ts, package.json): make small exact-string Edit calls and re-read right before editing, since others edit the same files. After all finish: lead runs `npm run typecheck` equivalents (tsc --noEmit x2), then docs.
